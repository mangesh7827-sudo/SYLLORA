# Syllora — Firebase Edition

Syllora is a React + Vite academic productivity app backed entirely by Firebase. There is no Express server, PostgreSQL database, Prisma layer, or custom authentication server.

## Stack

- React + TypeScript + Vite
- Firebase Authentication — email/password, Google sign-in, password reset
- Cloud Firestore — user-scoped academic/productivity data
- Firebase Storage — ready for user file storage
- Firestore Security Rules — each signed-in user can access only their own data
- Firebase Hosting — SPA deployment configuration included

## Configure Firebase

1. Create a Firebase project.
2. Add a Web App in Firebase Project Settings.
3. Enable Authentication providers: Email/Password and Google.
4. Create a Cloud Firestore database.
5. Enable Storage if you want file uploads.
6. Copy `.env.example` to `.env` and paste the Web App configuration values.
7. Run `npm install`.
8. Run `npm run dev`.

The Firebase web configuration is not a secret; Firestore and Storage Security Rules are the security boundary.

## Deploy

Install Firebase CLI, authenticate, select your project, build, then deploy Hosting/Firestore/Storage rules.

```bash
npm run build
firebase deploy --only hosting,firestore:rules,firestore:indexes,storage
```

## Important

Firebase scheduled push notifications are not generated by the browser alone. The current app persists notification records and preferences in Firestore. Automated lecture/assignment/habit reminders can be added later with Firebase Cloud Functions + Firebase Cloud Messaging without changing the database model.
